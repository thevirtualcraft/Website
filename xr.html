About this scene

Aurora Atrium is a small WebXR sketch we built to show what a browser-first immersive room can feel like. The same scene runs on phones, laptops and VR headsets — no install required.

Controls

  • Click+drag — look around
  • WASD — move
  • Tap a pillar — switch room mood
  • VR headset — tap the goggles icon (bottom-right) to enter

Built with

A-Frame 1.5 · WebXR Device API · three.js · open glTF assets.
