# The Virtual Craft — Website

Modern, immersive website for [thevirtualcraft.com](https://thevirtualcraft.com) featuring WebXR integration, interactive 3D scenes, and a showcase for immersive content.

## Tech Stack

- **Framework:** Next.js 14 (React 18)
- **Styling:** Tailwind CSS with custom design tokens
- **3D/WebXR:** Three.js, React Three Fiber, React Three Drei, React Three XR
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Language:** TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- Immersive hero section with animated 3D sphere, particle field, and orbital rings
- Interactive WebXR viewer with orbit controls, clickable 3D objects, and VR-ready detection
- Portfolio showcase grid with hover effects and project categories
- Services section highlighting WebXR, AR, 3D web, and spatial computing capabilities
- Contact form with project type selection
- Fully responsive design with mobile navigation
- Glass-morphism UI, smooth scroll-triggered animations, and dark theme
- SEO-optimized metadata and Open Graph tags

## Build

```bash
npm run build
npm start
```
